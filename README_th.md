# HelixCraft

**ซอฟต์แวร์เดสก์ท็อปช่วยงานวิศวกรรมพันธุกรรมที่ขับเคลื่อนด้วย AI** · AI-powered gene engineering tools

> HelixCraft เป็นซอฟต์แวร์เดสก์ท็อปสำหรับงานวิจัยด้านชีววิทยาโมเลกุลและวิศวกรรมพันธุกรรม ครอบคลุมขั้นตอนการทำงานครบวงจร "ค้นหายีน → อ่านซีเควนซ์ → ออกแบบการโคลนนิ่ง → ประกอบเสมือน → ตรวจสอบด้วยการทดลอง → จัดการข้อมูล" ทั้งการแก้ไขแผนที่เวกเตอร์ การออกแบบไพรเมอร์ การจำลองการตัดด้วยเอนไซม์ตัดจำเพาะและการเจลอิเล็กโทรโฟรีซิส เวิร์กโฟลว์การโคลนนิ่ง การวิเคราะห์โครมาโตแกรมผลซีเควนซ์ การค้นข้อมูลสปีชีส์ การวิเคราะห์โปรตีน และผู้ช่วย AI แบบเลือกใช้ ข้อมูลทั้งหมดจัดเก็บบนเครื่องของคุณเอง ไม่ต้องสมัครบัญชี ไม่ต้องพึ่งพาคลาวด์ และรองรับอินเทอร์เฟซ 20 ภาษา
> เอกสารฉบับเต็ม: [简体中文](README.md) · [English](README_EN.md)

## ใช้ทำอะไรได้บ้าง

- เปิดไฟล์พลาสมิดเพื่อดูองค์ประกอบและตำแหน่งตัดจำเพาะได้ชัดเจนในภาพเดียว และส่งออกแผนที่เป็นภาพคุณภาพสำหรับงานตีพิมพ์
- จำลองแผนการโคลนนิ่งแบบ Gibson / Golden Gate / ตัดด้วยเอนไซม์แล้วเชื่อมต่อกันให้ครบทุกขั้นตอนบนคอมพิวเตอร์ ก่อนลงมือเตรียมปฏิกิริยาจริง
- ออกแบบไพรเมอร์สำหรับโคลนนิ่ง หรือไพรเมอร์ qPCR ที่คร่อมรอยต่อเอกซอน พร้อมคะแนนประเมินและเหตุผลอ้างอิงที่ตรวจสอบได้
- ดูโครมาโตแกรมผลซีเควนซ์ ประกอบ read หลายเส้นเข้าด้วยกัน แล้วนำผลกลับไปเทียบกับเวกเตอร์รีคอมบิแนนต์เพื่อตรวจยืนยัน
- ใส่คำอธิบายประกอบเลนและแถบบนภาพเจล พร้อมวิเคราะห์เชิงปริมาณ
- เริ่มจากซีเควนซ์โปรตีนเพื่อวิเคราะห์สมบัติทางเคมีกายภาพ ตำแหน่งในเซลล์ ตำแหน่งที่ถูกปรับแต่ง และโครงสร้างสามมิติ
- จัดการเวกเตอร์ ยีน ไพรเมอร์ และไฟล์ผลซีเควนซ์ตามโครงการวิจัย ถ่ายโอนระหว่างเครื่องในห้องปฏิบัติการ และสำรองข้อมูลตามรอบ

## ดาวน์โหลด

เวอร์ชันล่าสุดอยู่ที่ [**Releases · ช่องทาง `latest`**](releases/tag/latest) เสมอ:

| แพลตฟอร์ม | ไฟล์ติดตั้ง | วิธีติดตั้ง |
|---|---|---|
| Windows 10 / 11 (x64) | `HelixCraft.Setup.<version>.exe` | ดับเบิลคลิกเพื่อเรียกตัวช่วยติดตั้ง |
| Debian / Ubuntu (x86_64) | `helixcraft_<version>_amd64.deb` | ดับเบิลคลิกเพื่อส่งต่อให้โปรแกรมติดตั้งกราฟิกของระบบ หรือ `sudo apt install ./<ไฟล์>` |

ช่องทาง `latest` ยังเป็นแหล่งข้อมูลของการ "ตรวจสอบการอัปเดต" ภายในแอปด้วย เวอร์ชันเก่าดูได้จาก [รายการ Releases](releases) โดยแต่ละเวอร์ชันมีคลังเก็บเป็นของตัวเอง ไฟล์ `latest.json` ในตำแหน่งเดียวกันคือรายการอัปเดตที่แอปใช้ ระบุชื่อไฟล์ ขนาด และค่า SHA-256 ของไฟล์ติดตั้งทุกไฟล์ ไว้ใช้ยืนยันว่าการดาวน์โหลดสมบูรณ์และไม่ถูกดัดแปลง

## การติดตั้ง

### Windows

- เรียก `HelixCraft.Setup.<version>.exe` แล้วทำตามตัวช่วยติดตั้งจนเสร็จ (ค่าเริ่มต้นติดตั้งสำหรับผู้ใช้ทุกคนบนเครื่อง ต้องมีสิทธิ์ผู้ดูแลระบบ)
- ตัวช่วยติดตั้งมีส่วนประกอบ **ข้อมูลตัวอย่าง** ให้เลือก (พลาสมิดตัวอย่าง เวิร์กโฟลว์การโคลนนิ่ง และปลั๊กอินข้อมูลสปีชีส์) เพื่อให้ผู้ใช้ใหม่ลองใช้ได้ทันที ข้อมูลตัวอย่างจะนำเข้าเฉพาะเมื่อยังไม่มีเนื้อหานั้นอยู่ **ไม่มีวันเขียนทับข้อมูลที่คุณสร้างไว้**
- **การติดตั้งทับเวอร์ชันเดิมจะเก็บข้อมูลทั้งหมดไว้ครบ** ไดเรกทอรีข้อมูลคือ `%APPDATA%\HelixCraft` (ฐานข้อมูลย่อยของสปีชีส์อยู่ที่ `%APPDATA%\HelixCraftData`) และการถอนการติดตั้งจะไม่ลบทิ้ง

### Linux (Debian / Ubuntu, x86_64)

- ดับเบิลคลิกไฟล์ `.deb` ระบบจะส่งต่อให้โปรแกรมติดตั้งแบบกราฟิก (GNOME Software / App Center / KDE Discover / GDebi) หรือสั่งในเทอร์มินัลด้วย `sudo apt install ./helixcraft_<version>_amd64.deb`
- โปรแกรมติดตั้งไว้ที่ `/opt/HelixCraft` ข้อมูลผู้ใช้อยู่ที่ `~/.config/HelixCraft` และ **การถอนการติดตั้งจะไม่ลบข้อมูลเหล่านี้**
- แนะนำให้เครื่องมีฟอนต์ CJK (แพ็กเกจประกาศ `Recommends: fonts-noto-cjk` หากติดตั้งด้วย `dpkg -i` โดยตรงจะไม่ติดตั้งรายการที่แนะนำมาด้วย โปรดใช้ `apt install` แทน)

## การอัปเดตออนไลน์

เมื่อเปิดแอปได้ประมาณ 20 วินาที โปรแกรมจะตรวจสอบการอัปเดตในเบื้องหลัง (เปิดใช้ตามค่าเริ่มต้น ตรวจได้อย่างมากครั้งเดียวใน 24 ชั่วโมง และปิดได้ในหน้าการตั้งค่า) เมื่อพบเวอร์ชันใหม่จะแจ้งเตือนเท่านั้น **ไม่ดาวน์โหลดอัตโนมัติ** การดาวน์โหลดใช้ HTTPS ตลอดเส้นทาง รองรับการดาวน์โหลดต่อจากจุดที่ขาด และตรวจสอบความถูกต้องด้วย SHA-256 ไฟล์ที่การตรวจสอบไม่ผ่านจะถูกปฏิเสธ บน Windows ตัวช่วยติดตั้ง NSIS จะทำการติดตั้งและรีสตาร์ทแอปให้อัตโนมัติ ส่วนบน Linux ไฟล์ `.deb` ที่ดาวน์โหลดแล้วจะถูกส่งต่อให้โปรแกรมติดตั้งของระบบ

## ฟังก์ชันหลัก

- **แผนที่เวกเตอร์และการแก้ไขซีเควนซ์โดยตรง**: แผนที่วงกลม/เส้นตรงเชื่อมสองทางกับข้อความซีเควนซ์ คลิกบนแผนที่เพื่อเลือกช่วงซีเควนซ์ คลิกบนซีเควนซ์เพื่อระบุตำแหน่งบนแผนที่ องค์ประกอบระบายสีตามประเภท ซ้อนทับด้วยตำแหน่งตัดจำเพาะ ตำแหน่งที่ไพรเมอร์จับ ORF และตำแหน่งกลายพันธุ์ ปรับแต่งรูปแบบแผนที่ได้อิสระ (สี ขนาดตัวอักษร คำอธิบายภาพ การแสดง/ซ่อน) และส่งออกเป็น SVG / PDF เพื่อทำภาพประกอบงานตีพิมพ์ พร้อมแก้ไขซีเควนซ์ได้โดยตรง (พิมพ์/ลบ/วาง) พิกัดองค์ประกอบปรับตามอัตโนมัติ และทุกการแก้ไขรองรับเลิกทำ/ทำซ้ำ 50 ขั้น
- **คำอธิบายประกอบอัจฉริยะ**: เทียบซีเควนซ์เวกเตอร์ทั้งเส้นกับฐานข้อมูลองค์ประกอบเพื่อจำแนกองค์ประกอบที่รู้จักโดยอัตโนมัติ (ยอมรับเฉพาะเมื่อ DNA ตรงกัน ≥99% หรือผลแปลรหัสตรงกัน ≥90% และให้ตรวจทานทีละรายการก่อนนำเข้าเป็นกลุ่มเสมอ) พร้อมอนุมานฟิลด์ของเวกเตอร์ เช่น ยีนดื้อยาปฏิชีวนะ โฮสต์ โปรโมเตอร์ ยีนรายงานผล โดยระบุความเชื่อมั่นและหลักฐานกำกับ และไม่เขียนทับข้อมูลที่มีอยู่เดิม
- **การทำนาย ORF และการค้นหาด้วย BLAST ออนไลน์**: สแกนครบทั้ง 6 เฟรม (รองรับ ORF ที่คล่อมจุดตั้งต้น (origin) ของพลาสมิดวงกลม) ผลลัพธ์แสดงบนแผนที่และคลิกไปยังตำแหน่งได้ และเลือกซีเควนซ์ส่งไปค้นที่ NCBI ได้ (blastn / blastp / blastx รวม 5 โปรแกรม)
- **การจำลองการตัดด้วยเอนไซม์และการเจลอิเล็กโทรโฟรีซิสเสมือน**: การตัดด้วยเอนไซม์เดี่ยว/สองชนิด/หลายชนิดให้รายการแฟรกเมนต์แบบเรียลไทม์ โดยจัดการตำแหน่งที่คล่อมจุดตั้งต้นของพลาสมิดวงกลมได้ถูกต้อง ส่งผลการตัดเข้าสู่การจำลองเจลได้ทันที เลือกมาร์กเกอร์ (DL2000, 1kb Ladder ฯลฯ 11 แบบที่ใช้ทั่วไป) ความเข้มข้นของอะกาโรส แรงดันไฟฟ้า และเวลาวิ่งเจล ตำแหน่งแถบคำนวณตามแบบจำลองการเคลื่อนที่ที่สอบเทียบกับวรรณกรรม เพื่อคาดการณ์ล่วงหน้าว่าการตัดเพื่อตรวจยืนยันจะแยกแถบเป้าหมายได้หรือไม่ พร้อมตรวจผลของเมทิลเลชัน (Dam / Dcm / CpG) ให้อัตโนมัติ และมีผู้ช่วยแนะนำตำแหน่งตัดจำเพาะและตัวเลือกที่เหมาะสมที่สุดเมื่อยังตัดสินใจไม่ได้
- **ผืนผ้าใบเวิร์กโฟลว์การโคลนนิ่ง**: ต่อขั้นตอนการทดลองเหมือนวาดผังงาน ตั้งแต่แหล่งซีเควนซ์ → ออกแบบไพรเมอร์/เพิ่มประสิทธิ์โคดอน → PCR เสมือน → ตัดด้วยเอนไซม์/ทำให้บริสุทธิ์ → ประกอบ → ทรานส์ฟอร์เมชัน/โคลอนี PCR/ตรวจยืนยันด้วยการซีเควนซ์ → บันทึกกลับสู่ฐานข้อมูล รวม 30 ชนิดของโหนด ผลลัพธ์ของทุกโหนด **คำนวณแบบเรียลไทม์** เมื่อแก้อินพุตต้นน้ำ ส่วนปลายน้ำจะจำลองใหม่ทันที เมื่อเชื่อมต่อครบก็ดูซีเควนซ์เต็มของพลาสมิดรีคอมบิแนนต์สุดท้ายได้ และถือว่าการออกแบบเสร็จสมบูรณ์เมื่อผลตรงกับที่คาดหวัง รองรับเลิกทำ/ทำซ้ำ บันทึกอัตโนมัติ และนำเข้า/ส่งออก JSON กลยุทธ์การประกอบครอบคลุม Gibson, Golden Gate (BsaI / BbsI / BpiI / SapI พร้อมคำแนะนำเบสป้องกัน), T4 ligation, TA / TOPO, Gateway LR / BP และ BioBrick
- **ผืนผ้าใบสร้างโมเลกุล (เบตา)**: เหมาะกับการออกแบบสไตล์ "เลือกแบ็กโบน ใส่องค์ประกอบ" เลือกแบ็กโบนจากคลังเวกเตอร์ เติมองค์ประกอบลงช่องว่าง เลือกวิธีประกอบ แล้วซอฟต์แวร์จะสร้างวิธีทำให้เป็นเส้นตรง ซีเควนซ์ไพรเมอร์ทั้งหมด สูตรประกอบปฏิกิริยา แฟรกเมนต์สำหรับตรวจโคลอนี PCR และคำแนะนำไพรเมอร์สำหรับซีเควนซ์ให้อัตโนมัติ **ผลิตภัณฑ์จะบันทึกลงฐานข้อมูลได้ก็ต่อเมื่อตรงกับการออกแบบระดับเบสเท่านั้น**
- **การออกแบบไพรเมอร์**: ออกแบบทั่วไป 3 โหมด (เพิ่มจำนวนช่วงที่เลือก / หาไพรเมอร์ภายในช่วงที่เลือก / เพิ่มจำนวนจากบริเวณข้างเคียง) ปรับพารามิเตอร์ได้กว่า 50 รายการ เช่น Tm, GC, ความยาวผลิตภัณฑ์ ความเสถียรของปลาย 3′ คัดให้ 20 อันดับแรก พร้อมค่า Tm, GC%, ความเสี่ยง hairpin/ไดเมอร์ และคะแนนรวมเต็ม 100 ด้าน qPCR มีตัวช่วยที่ทำการเทียบลำดับแบบสไปลซ์ (splice alignment) ระหว่าง mRNA กับจีโนมให้อัตโนมัติ วาดโครงสร้างเอกซอน แล้วออกแบบตามกลยุทธ์ย่อยที่ดีที่สุดเป็นลำดับ โดยให้ไพรเมอร์คร่อมรอยต่อเอกซอนเป็นอันดับแรก ตามด้วยแอมพลิคอนที่คร่อมอินทรอน ป้องกันการรบกวนจากจีโนมิก DNA ตั้งแต่กลไก ผลลัพธ์แนบคะแนนความสอดคล้อง MIQE และเชื่อมโยงกับยีนอัตโนมัติเมื่อบันทึก ทุกคู่ไพรเมอร์ทดสอบ in-silico PCR ดูขนาดผลิตภัณฑ์ที่คาดหวังและการเพิ่มจำนวนที่ไม่จำเพาะได้ล่วงหน้า ส่วนคลังไพรเมอร์จัดการเป็นคู่ไพรเมอร์ (qPCR/ทั่วไป/โคลนนิ่ง/การตรวจพบ) รองรับการผูกยีน การจัดโครงการ การนำเข้า/ส่งออก Excel และประวัติการแก้ไขสำหรับตรวจสอบย้อนหลัง
- **การวิเคราะห์ผลซีเควนซ์**: เปิดไฟล์ AB1 เพื่อดูกราฟพีคเรืองแสงสี่ช่องสัญญาณและค่าคุณภาพ เทียบกับซีเควนซ์อ้างอิงทีละเบส และแก้ไขด้วยมือพร้อมบันทึกได้เมื่อจำเป็น (ยึดผลจากเครื่องซีเควนซ์เป็นมาตรฐาน อัลกอริทึมจะไม่เขียนทับเงียบ ๆ) ประกอบ read ของ Sanger หลายเส้นโดยอัตโนมัติด้วยอัลกอริทึม CAP3 ได้ลำดับฉันทามติ (consensus) ของ contig พร้อมความลึกการครอบคลุมและคำเตือนบริเวณคุณภาพต่ำ เมื่อประกอบเสร็จส่งไปเทียบลำดับต่อได้ทันที และเทียบ read กลับกับเวกเตอร์รีคอมบิแนนต์เพื่อตรวจยืนยัน โดยเลือกทิศทางสายที่ดีกว่าให้อัตโนมัติ (รองรับเวกเตอร์วงกลมที่คล่อมจุดตั้งต้นด้วย) ได้ไดอะแกรม "องค์ประกอบเวกเตอร์ + การจัดวาง read" ที่ระบายสีตามระดับความตรงกัน เห็น mismatch/insertion/deletion ได้ชัดเจน รวมถึงการเทียบลำดับหลายสาย (ClustalW) และการสร้างแผนภาพวิวัฒนาการ
- **การวิเคราะห์ภาพเจลด้วย AI**: ตัวช่วย 3 ขั้นตอน เปิดภาพเจล → โมเดลดีปเลิร์นนิงในตัวตรวจจับเลนและแถบโดยอัตโนมัติ (เพิ่ม/ลบ/ลากตำแหน่งเพื่อปรับด้วยมือได้) → วิเคราะห์เชิงปริมาณ เมื่อระบุเลนมาร์กเกอร์ ชนิดแลดเดอร์ และปริมาณของแถบอ้างอิง ระบบจะฟิตเส้นมาตรฐานของขนาดให้อัตโนมัติ รายงาน **ขนาดแฟรกเมนต์และปริมาณ DNA** ของทุกแถบ (วิธีความหนาแน่นแสงเชิงปริพันธ์ IOD) ตำแหน่งป้ายกำกับลากปรับได้ ส่งออกภาพวิเคราะห์พร้อมคำอธิบายประกอบ (PNG / JPG / BMP / TIF) และผลเชิงปริมาณเป็น JSON หากแก้ไขคำอธิบายประกอบภายหลัง ระบบจะแจ้งอัตโนมัติว่าผลเชิงปริมาณหมดอายุและต้องคำนวณใหม่
- **การวิเคราะห์โปรตีน**: สามมุมมองเชื่อมโยงกัน ไดอะแกรมโทโพโลยี (ทรานส์เมมเบรน ซิกแนลเปปไทด์ โครงสร้างรองแบบการ์ตูน) ↔ แผงซีเควนซ์กรดอะมิโน (เลือกได้หลายช่วง) ↔ โครงสร้างสามมิติ (ดึงจาก RCSB PDB / AlphaFold DB ให้อัตโนมัติ) คลิกตำแหน่งหรือช่วงใดก็ไฮไลต์ซีเควนซ์และโครงสร้างพร้อมกัน วิเคราะห์ในเครื่องเสร็จภายในไม่กี่วินาที ทั้งน้ำหนักโมเลกุล จุดไอโซอิเล็กทริก ความไม่ชอบน้ำ องค์ประกอบกรดอะมิโน การคาดคะเนตำแหน่งในเซลล์ (ซิกแนลเปปไทด์ ทรานส์เมมเบรน สัญญาณนำทางเข้านิวเคลียัส ฯลฯ พร้อมจัดอันดับคอมพาร์ตเมนต์และระบุความเชื่อมั่น) ตำแหน่งการปรับแต่งหลังการแปลรหัส 7 ประเภท เช่น ฟอสโฟรีเลชัน ยูบิควิติเนชัน ไกลโคซิเลชัน และบริเวณไร้โครงสร้าง บริเวณความซับซ้อนต่ำ คอยล์-คอยล์ และบริเวณแอนติเจน ฝั่งออนไลน์จะส่งตำแหน่งที่คะแนนสูงสุดไปสแกนโดเมนด้วย InterProScan และค้นหาลำดับใกล้เคียงด้วย BLAST โดยอัตโนมัติ เพื่อโอนคำอธิบายประกอบที่ Swiss-Prot ตรวจสอบแล้วมาใส่ให้ (เติมเท่านั้น ไม่เขียนทับข้อสรุปในเครื่อง พร้อมระบุแหล่งที่มา) นำเข้า/ส่งออกคำอธิบายประกอบโปรตีนได้หลายรูปแบบ เช่น UniProtKB / GFF3 / InterProScan / GenPept และแพ็กเกจโปรตีน (`.hcp`) ที่รวมซีเควนซ์ โครงสร้าง คำอธิบายประกอบ และการตั้งค่าการแสดงผลไว้ในไฟล์เดียวเพื่อแบ่งปัน
- **การจัดการข้อมูลห้องปฏิบัติการ**: ฐานข้อมูลใหญ่ 5 คลัง ได้แก่ คลังเวกเตอร์ (ต้นแบบ/รีคอมบิแนนต์ จัดกลุ่มงานได้สองระดับ) ฐานข้อมูลซีเควนซ์ (ไฟล์ผลซีเควนซ์ ซีเควนซ์ยีน และซีเควนซ์อื่น ๆ รวมในมุมมองเดียว กรองตามความเชื่อมโยงยีน/โครงการ/เวกเตอร์/ไพรเมอร์ได้) คลังไพรเมอร์ คลังเอนไซม์ (ข้อมูลเอนไซม์ตัดจำเพาะกว่า 580 ชนิด ทั้งลำดับจำเพาะ ตำแหน่งตัด ประเภท ชนิดปลาย และอุณหภูมิ เพิ่มเอนไซม์ที่กำหนดเองได้) และตัวจัดการโครงการ (ผูกเวกเตอร์/ยีน/ไพรเมอร์/ไฟล์ผลซีเควนซ์ตามโครงการวิจัย) แบ่งปันข้อมูลได้ทั้งกลุ่มงานผ่านไฟล์ `.hcvec` โดยผู้รับตรวจทานทีละรายการก่อนนำเข้า คอมพิวเตอร์สองเครื่องที่ติดตั้ง HelixCraft ในเครือข่ายเดียวกันถ่ายโอนข้อมูลกันได้อย่างเข้ารหัสผ่านรหัสจับคู่ 8 หลัก ฝั่งรับเติมเฉพาะช่องที่ว่าง ไม่เขียนทับการแก้ไขเดิม มีการสำรองข้อมูลอัตโนมัติเมื่อเปิดโปรแกรม (เก็บไว้ 5 ชุด) สำรองแบบเต็มด้วยมือเป็นไฟล์ ZIP ไฟล์เดียว และกู้คืนได้ในคลิกเดียว การลบมีระบบป้องกัน ก่อนลบเวกเตอร์/ยีน/ไพรเมอร์จะแสดงข้อมูลที่เกี่ยวข้องทั้งหมดให้คุณเลือกขอบเขตการลบ
- **ผู้ช่วย AI (ฟังก์ชันเสริม)**: ใช้งานได้เมื่อตั้งค่าบริการโมเดลที่รองรับรูปแบบ OpenAI ได้ (API Key เก็บไว้ในเครื่องของคุณเท่านั้น) รองรับแชทแบบสตรีม ป้อนด้วยเสียง อ่านคำตอบให้ฟัง และขัดเกลาพรอมป์ **รับรู้และสั่งงานซอฟต์แวร์ได้** รู้ว่าคุณกำลังเปิดยีน/เวกเตอร์/หน้าต่างใดอยู่ สลับหน้าจอ ค้นหารายการ และแก้ไขข้อมูลตามคำขอได้ โดยการแก้ไขใช้เส้นทางเดียวกับการแก้ด้วยมือทุกประการและย้อนกลับได้ **ถอดความแผนการโคลนนิ่งจากข้อความได้** วางย่อหน้าวิธีทดลองจากงานวิจัยหรือคำบรรยายปากเปล่า ให้ AI สกัดเป็นแผนเชิงโครงสร้าง (แบ็กโบน แฟรกเมนต์ที่จะใส่ เอนไซม์ วิธีประกอบ) แล้วเอนจินที่ทำงานแบบกำหนดได้ของซอฟต์แวร์จะสร้างไพรเมอร์และคำแนะนำการทดลองต่อ **AI ทำหน้าที่เข้าใจข้อความเท่านั้น ไม่สร้างซีเควนซ์เบสขึ้นเองเด็ดขาด** เมื่อไม่ตั้งค่า AI ทุกฟังก์ชันยังมีทางทำด้วยมือครบถ้วน ซอฟต์แวร์ใช้งานได้เต็มรูปแบบ

## ปลั๊กอินข้อมูลสปีชีส์

คำอธิบายประกอบของยีนและข้อมูลการแสดงออกเข้าถึงได้ผ่าน "ปลั๊กอินข้อมูลสปีชีส์" ซึ่งติดตั้ง/เปิดใช้/ถอนการติดตั้งได้ในหน้าการตั้งค่า ไฟล์ติดตั้งมาพร้อมข้อมูลคำอธิบายประกอบของข้าวในตัว (ประมาณ 100,000 รายการ) ข้อมูลที่ดึงจากออนไลน์จะถูกบันทึกลงแคชในเครื่องโดยอัตโนมัติ จากนั้นอ่านจากแคชเป็นค่าเริ่มต้น (กดรีเฟรชจึงจะเชื่อมต่อใหม่) จึงยังดูได้แม้ออฟไลน์ แม้ไม่ติดตั้งปลั๊กอิน ก็ยังนำเข้ายีนของสปีชีส์ใดก็ได้จาก NCBI โดยตรง

| ปลั๊กอิน | แหล่งข้อมูล | สิ่งที่ได้รับ |
|---|---|---|
| ข้าว (Rice) | RAP-DB, MSU-RGAP, RiceData, RiceXPro | คำอธิบายประกอบโลคัส โครงสร้างเอกซอน ชื่อพ้อง ฟีโนไทป์ของมิวแทนต์ แผนภาพการแสดงออกตามช่วงเวลาและเนื้อเยื่อ (ค่าตัวเลข + ภาพ) ซีเควนซ์ทุกรุ่น และการแปลงรหัสข้ามฐานข้อมูล |
| Ensembl Plants | Ensembl Plants, EBI Expression Atlas | ค้นหายีนในกว่า 100 สปีชีส์ ดาวน์โหลดซีเควนซ์ คำอธิบายประกอบ GO และข้อมูลการแสดงออกจาก RNA-Seq |
| Phytozome | JGI Phytozome | ค้นหายีน โมเดลยีน ซีเควนซ์ CDS / cDNA / โปรตีน โดเมน และยีนโฮโมโลกัส |
| ePlant (BAR) | BAR eFP Browser | แผนภาพสีการแสดงออกในเนื้อเยื่อและระดับการแสดงออกรายเนื้อเยื่อของ 13 สปีชีส์ |

## ความปลอดภัยของข้อมูลและความเป็นส่วนตัว

- **ข้อมูลทั้งหมดจัดเก็บในเครื่อง**: ไม่มีการอัปโหลดขึ้นเซิร์ฟเวอร์ใด ๆ การเชื่อมต่ออินเทอร์เน็ตเกิดขึ้นเฉพาะเมื่อคุณร้องขอข้อมูลออนไลน์ด้วยตัวเอง (NCBI ฐานข้อมูลสปีชีส์ คลังโครงสร้างโปรตีน และการอัปเดตซอฟต์แวร์)
- **ปิด AI ได้ทั้งหมด**: ผู้ช่วย AI เป็นฟังก์ชันเสริม ต้องใช้ API Key ของคุณเองซึ่งเก็บไว้ในเครื่องเท่านั้น เมื่อไม่ตั้งค่า AI ทุกฟังก์ชันยังมีเส้นทางทำด้วยมือให้ใช้ครบถ้วน
- **การรวมข้อมูลไม่เขียนทับ**: การติดตั้งข้อมูลตัวอย่าง การนำเข้าแพ็กเกจข้อมูล และการรับถ่ายโอนผ่านเครือข่ายเฉพาะที่ ล้วนเติมเฉพาะช่องที่ว่าง ไม่แตะต้องเนื้อหาเดิมของคุณ

| ประเภท | รูปแบบ |

## ภาษาอินเทอร์เฟซ

ตั้งแต่ v0.3.7 ทุกโมดูลฟังก์ชันรองรับภาษาครบทั้ง 20 ภาษา: 简体中文, English, 日本語, 한국어, Français, Deutsch, Español, Português, Русский, Italiano, العربية, हिन्दी, ไทย, Tiếng Việt, Bahasa Indonesia, Türkçe, Nederlands, Polski, Svenska, Čeština — เปลี่ยนได้ตลอดเวลาที่ "การตั้งค่า → ภาษา" และหน้าจอแรกของตัวช่วยติดตั้งก็เลือกภาษาได้เช่นกัน เอกสารแนะนำโครงการของแต่ละภาษาอยู่ในแถบเลือกภาษาด้านบนของไฟล์นี้

## เกี่ยวกับที่เก็บนี้

ที่เก็บนี้ใช้สำหรับ **เผยแพร่ไฟล์ติดตั้งและรายการอัปเดตออนไลน์เท่านั้น** ไม่มีซอร์สโค้ดรวมอยู่ Release ที่แท็ก `latest` คือช่องทางการอัปเดตออนไลน์ (ไฟล์ประกอบถูกแทนที่ทุกครั้งที่มีเวอร์ชันใหม่) ส่วน Release ที่แท็ก `v<version>` เป็นคลังเก็บเวอร์ชันเก่า ที่เก็บเดียวกันถูกโฮสต์แบบซิงก์ทั้งที่ [GitHub](https://github.com/liudab/HelixCraft) และ [GitCode](https://gitcode.com/BohanLab/HelixCraft) โดยไฟล์ติดตั้งเผยแพร่พร้อมกันทั้งสองแห่ง
