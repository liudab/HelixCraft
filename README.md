# HelixCraft

**AI 赋能的基因工程辅助桌面软件** · AI-powered gene engineering tools

**简体中文** · [English](README_EN.md)

HelixCraft 是一款面向分子生物学与基因工程研究的桌面软件，帮助你完成从「查基因 → 读序列 →
设计克隆 → 虚拟组装 → 实验验证 → 数据管理」的完整工作流：载体图谱编辑、序列分析、引物设计、
酶切与凝胶电泳模拟、克隆工作流、测序峰图分析、物种数据检索、蛋白分析，以及可选的 AI 助手。
所有数据存储在你自己的电脑上，无需注册账号、不依赖云端；界面支持 20 种语言。

它适合这些日常场景：

- 拿到质粒图谱文件后，想看清元件组成与酶切位点，并导出发表用的图谱图片；
- 在动手配反应之前，先把 Gibson / Golden Gate / 酶切连接方案在计算机里完整模拟一遍；
- 设计克隆引物或跨外显子的 qPCR 定量引物，需要带评分与评估依据的设计工具；
- 查看测序峰图、拼接读段、把测序结果比对回重组载体核对；
- 给凝胶照片做泳道/条带标注与定量分析；
- 从一段蛋白序列出发，分析理化性质、亚细胞定位、修饰位点与三维结构；
- 按课题管理载体、基因、引物与测序文件，在课题组电脑间传输、定期备份。

## 下载

最新版本始终在 [**Releases · latest 频道**](https://github.com/liudab/HelixCraft/releases/tag/latest)：

| 平台 | 安装包 | 安装方式 |
|---|---|---|
| Windows 10 / 11（x64） | `HelixCraft.Setup.<版本>.exe` | 双击运行安装向导 |
| Debian / Ubuntu（x86_64） | `helixcraft_<版本>_amd64.deb` | 双击交给系统图形化安装器，或 `sudo apt install ./<文件>` |

`latest` 频道同时是应用内「检查更新」的数据源，资产随每个版本覆盖式替换。历史版本见
[Releases 列表](https://github.com/liudab/HelixCraft/releases)，每个版本都有独立存档。

### 校验下载

同目录下的 `latest.json` 是应用使用的更新清单，其中列出了每个安装包的文件名、字节数与
SHA-256 摘要，可用于校验下载是否完整、是否被篡改。例如：

```bash
# Linux
sha256sum helixcraft_<版本>_amd64.deb
# Windows PowerShell
Get-FileHash .\HelixCraft.Setup.<版本>.exe -Algorithm SHA256
```

## 安装

### Windows

- 系统要求：Windows 10 及以上（x64）。
- 运行 `HelixCraft.Setup.<版本>.exe`，按向导完成安装（默认为所有用户安装，需管理员权限）。
- 安装向导提供可选的**示例数据**组件（示例载体、克隆工作流与物种数据插件），方便新用户直接
  上手体验；示例数据只在对应内容不存在时导入，**永远不会覆盖你已建立的数据**。
- **覆盖安装会保留全部既有数据**。数据目录为 `%APPDATA%\HelixCraft`（物种子库位于
  `%APPDATA%\HelixCraftData`），卸载不会删除该目录。

### Linux（Debian / Ubuntu，x86_64）

- 双击 `.deb` 会交由系统的图形化安装器（GNOME Software / App Center / KDE Discover / GDebi）；
  终端等价命令：`sudo apt install ./helixcraft_<版本>_amd64.deb`。
- 程序安装到 `/opt/HelixCraft`，用户数据在 `~/.config/HelixCraft`，**卸载不会删除**。
- 界面以中文为主，建议系统装有 CJK 字体（包内声明 `Recommends: fonts-noto-cjk`；用
  `dpkg -i` 直接安装不会带上依赖，请改用 `apt install`）。
- 依赖按 `libgtk-3-0 | libgtk-3-0t64` 这类「二选一」形式声明，因此 Ubuntu 24.04 起的 t64
  重命名不会导致依赖无法满足。
- 未提供 AppImage。

### 直接打开文件

安装后以下文件可双击（或拖入软件窗口）直接用 HelixCraft 打开：GenBank（`.gb` `.gbk`）、
FASTA（`.fasta` `.fa`）、SnapGene（`.dna`）、EMBL（`.embl`）→ 序列编辑器；`.ab1` 测序峰图 →
峰图查看器；蛋白序列（`.faa` `.genpept`）与蛋白包（`.hcp`）→ 蛋白序列结构查看器；`.tif`
凝胶图像 → 凝胶图像分析。

## 在线更新

应用启动约 20 秒后会在后台检查更新（默认开启，24 小时内最多检查一次，可在设置中关闭）。
发现新版本只提醒、**不会自动下载**；下载全程 HTTPS，支持断点续传与 SHA-256 校验，校验不通过
的安装包会被拒绝。Windows 上安装由 NSIS 向导完成并自动重启；Linux 上则把下载好的 `.deb`
交给系统的软件安装器，若系统无法拉起安装器，界面会给出安装包路径与「在文件夹中显示」。

## 功能总览

### 查找与研究一个基因

- **多种途径找基因**：本地基因库搜索；输入 NCBI Gene ID / Accession 直接导入；通过物种
  数据插件按编号检索（水稻 RAP-DB / MSU / RiceData 编号、Ensembl Plants 稳定 ID、Phytozome
  基因号）；导入本地 GenBank / FASTA 文件或同事分享的基因数据包。
- **基因详情页一站看全**：各物种数据库注释汇总（等位基因、突变体表型、GO / InterPro、
  参考文献）；时空表达模式（表达图谱与组织表达热图）；该基因的基因组 / mRNA / CDS / 蛋白
  序列统一管理，需要时可从 NCBI 按需下载。
- 转录本变体可分别打开查看，蛋白序列一键转交蛋白结构查看器；重复条目可合并，删除前列出
  受影响数据由你决定范围。

### 载体图谱与序列编辑

- **环形 / 线性图谱与序列文本双向联动**：点图谱选序列、点序列定位图谱；元件按类型着色，
  酶切位点、引物结合位置、ORF、突变标记叠加显示；图谱样式（颜色、字号、图例、显隐）自由
  定制，可导出 SVG / PDF / PNG 等格式用于论文配图。
- **直接编辑序列**：键入 / 删除 / 粘贴均可，插入删除后元件坐标自动调整；序列与元件全部
  操作支持 50 步撤销 / 重做。
- **智能标注**：用载体全序列比对元件数据库自动识别已知元件（DNA 一致性 ≥99% 或翻译匹配
  ≥90% 才认定，批量导入前逐条预览确认），并自动推断该载体的抗生素抗性、宿主、启动子、
  报告基因等字段（附置信度与证据，已有信息不覆盖）。
- **ORF 预测**：六框扫描（支持环形质粒跨原点的 ORF），结果悬浮图谱可点击定位，翻译产物
  可存入序列数据库。
- **BLAST 在线搜索**：选中序列提交 NCBI（blastn / blastp / blastx 等五种程序）。
- **氨基酸替换（点突变）设计**：按 `G168A` 写法描述突变，自动校验原残基、选择改动最小的
  同义密码子并写回序列。

### 模拟酶切与虚拟电泳

- 单酶切 / 双酶切 / 多酶切实时给出片段列表，环形质粒跨原点的酶切同样正确处理。
- **虚拟凝胶电泳**：酶切结果一键送入凝胶模拟，选择 marker（DL2000、1kb Ladder 等 11 种
  常见型号）、琼脂糖浓度、电压与跑胶时间，按文献迁移模型推算条带位置，预判酶切鉴定能否
  分开目的条带。
- 酶切位点自动检查甲基化影响（Dam / Dcm / CpG），提示哪些位点在常见菌株中会被阻断。
- **酶切位点选择助手**：不确定克隆用哪个位点时，向导式推荐候选位点与首选。

### 设计克隆实验（计算机预演）

- **克隆工作流画布**：像搭流程图一样把实验连起来——序列源 → 引物设计 / 密码子优化 →
  虚拟 PCR → 酶切 / 纯化 → 组装 → 转化 / 菌落 PCR / 测序验证 → 存回数据库，共 30 种节点。
  每个节点的输出**实时计算**：改了上游输入，下游立刻重新模拟；连接完毕可查看最终重组质粒
  全序列，与预期一致才算设计完成。支持撤销 / 重做、自动保存与 JSON 导入导出。
- **组装策略**：Gibson、Golden Gate（BsaI / BbsI / BpiI / SapI，含保护碱基建议）、T4 连接、
  TA / TOPO 克隆、Gateway LR / BP、BioBrick。
- **分子构建画布（Beta）**：适合「选骨架、填元件」式设计——从载体库挑骨架、往缺口里添
  元件、选组装方法，软件自动生成线性化方式、全部引物序列、组装体系、菌落 PCR 验证片段与
  测序引物建议；产物与设计**逐碱基一致才允许入库**。
- **克隆系统知识库**：内置克隆系统语义模型（载体兼容关系与转换路径），辅助规划「从 A 载体
  到 B 载体」的改造路线。

### 引物设计

- **通用引物设计**：三种模式（扩增选中区间 / 选区内找引物 / 从侧翼扩增）；Tm、GC、产物
  长度、3′ 端稳定性等 50 余项参数可调；给出 Top20 候选，每对引物附 Tm、GC%、发夹 / 二聚体
  风险与百分制综合评分。
- **深度评估与人机协作**：假引发位点、引物效率、内部稳定性谱等进阶分析；对结果不满意时
  直接反馈意见（如「3′ 端太稳定」「Tm 偏低」），软件解析反馈并定向重新搜索。
- **qPCR 定量引物向导**：自动做 mRNA 与基因组的剪接比对、绘制外显子结构，按最佳策略分级
  设计——优先让引物跨外显子连接处，其次扩增子跨内含子，从机制上避免基因组 DNA 污染干扰
  定量；结果附 MIQE 合规性评分，保存时自动关联基因。
- **虚拟 PCR 验证**：任何一对引物都可先做 in-silico PCR，看预期产物大小与有无非特异扩增。
- **引物库**：按引物对管理（qPCR / 通用 / 克隆 / 检测四类），支持基因关联、项目归属、Excel
  导入导出与修改历史审计。

### 测序结果分析

- **峰图查看器**：打开 AB1 文件查看四通道荧光峰图与质量值，对照参考序列逐碱基核查；序列
  需要人工修正时可手动编辑保存（以测序仪输出为权威，算法不会偷偷覆盖）。
- **测序序列组装**：多条 Sanger 读段自动重叠拼接（CAP3 算法），输出 contig 一致序列、覆盖
  深度与低质量区提示，拼好的 contig 可一键送去比对。
- **重组载体验证比对**：测序读段对到你的载体上，自动选正反链较优方向（环形载体跨原点亦可），
  生成「载体元件 + 读段排布」示意图——按一致性分档着色，错配 / 插入 / 缺失一目了然；也支持
  多序列比对（ClustalW）与系统发育树构建。

### 凝胶图像分析

- **三步向导**：打开凝胶照片 → 内置深度学习模型自动识别泳道与条带（可手动增删、拖动微调）→
  定量分析。
- **定量**：选定 marker 泳道与梯带型号、指定参考条带含量后，自动拟合大小标准曲线，给出每
  个条带的**片段大小与 DNA 含量**（积分光密度法），标注位置可拖动。
- **导出**：带标注的分析图（PNG / JPG / BMP / TIF）与定量结果 JSON；中途修改标注会自动
  提示定量结果已过期需重新计算。

### 蛋白质分析

- **三视图联动**：拓扑示意图（跨膜区、信号肽、二级结构卡通）↔ 氨基酸序列面板（多区段选择）↔
  三维结构（自动从 RCSB PDB / AlphaFold DB 检索加载）；点击任意位点或区段，序列与结构同步
  高亮。
- **本地分析秒级出结果**：分子量、等电点、疏水性、氨基酸组成；亚细胞定位预测（信号肽、
  跨膜区、核定位信号等，附区室排序与置信度）；磷酸化 / 泛素化 / 糖基化等七类翻译后修饰位点；
  无序区、低复杂度区、卷曲螺旋、抗原性区段。
- **在线精算**：对评分最高的候选位点自动提交 InterProScan 结构域扫描与 BLAST 同源检索，把
  Swiss-Prot 已验证注释转移到你的序列上（只补充、不覆盖本地结论，标注来源）。
- **蛋白标注**：导入导出兼容 UniProtKB / GFF3 / InterProScan / GenPept 等格式；蛋白包
  （`.hcp`）把序列、结构、标注、渲染设置打包成一个文件便于分享。

### 实验室数据管理

- **五大数据库**：载体库（模板 / 重组载体、两级工作组分组）、序列数据库（测序文件、基因
  序列、其他序列统一视图，可按基因 / 项目 / 载体 / 引物关联过滤）、引物库、酶库（580+ 种
  限制酶的识别序列、切割图谱、类型、末端、温度资料，可自定义酶）、项目管理器（按课题挂载
  载体 / 基因 / 引物 / 测序文件）。
- **数据共享**：整个载体工作组可打包成 `.hcvec` 文件发给同事，对方导入时逐条预览决定；
  同一局域网内两台装了 HelixCraft 的电脑可通过 8 位配对码加密互传数据，接收端只补充空缺
  字段、不覆盖已有编辑。
- **备份与恢复**：启动自动备份（保留 5 份）、手动全量备份（单个 ZIP）与一键恢复。
- **删除有保护**：删除载体 / 基因 / 引物前列出所有受影响的关联数据，由你选择删除范围。

### AI 助手（可选）

- 配置任一 OpenAI 兼容的大模型接口后可用（API Key 只保存在本机）：流式对话、语音输入、
  朗读回复、提示词润色。
- **感知并操作软件**：它知道你当前打开的基因 / 载体 / 窗口，可按你的要求切换页面、定位
  实体、查询和修改数据——修改走与手动编辑完全相同的路径，可撤销。
- **克隆方案文字解析**：把文献方法段或口头描述贴给它，AI 提取出结构化方案（骨架、插入
  片段、酶、组装方法），再由软件的确定性引擎生成引物和实验指引——**AI 只负责理解文字，
  不产生任何碱基序列**。
- **不配置 AI 时，所有功能都有纯手动路径，软件完整可用。**

## 物种数据插件

基因注释与表达数据通过「物种插件」接入，可在设置页安装 / 启用 / 卸载。安装包内置水稻注释
数据（约 10 万条），并支持按插件接入在线数据源：

| 插件 | 覆盖数据源 | 你能拿到什么 |
|------|-----------|--------------|
| 水稻（Rice） | RAP-DB、MSU-RGAP、RiceData、RiceXPro | 基因座注释、外显子结构、同义词、突变体表型、时空表达图谱（数值 + 图片）、各版本序列、跨库编号互换 |
| Ensembl Plants | Ensembl Plants、EBI Expression Atlas | 100+ 物种的基因搜索、序列下载、GO 注释、RNA-Seq 表达 |
| Phytozome | JGI Phytozome | 基因搜索、基因模型、CDS / cDNA / 蛋白序列、结构域、同源基因 |
| ePlant（BAR） | BAR eFP Browser | 13 个物种的组织表达彩色象形图与逐组织表达量 |

在线获取的注释、序列、图片会自动保存到本地，之后默认读本地缓存（点刷新才重新联网），离线
也能查看。未安装插件时，也可以直接用 NCBI 导入任何物种的基因。

## 数据安全与隐私

- **全部数据本地存储**：不上传任何服务器；联网只发生在你主动请求在线数据（NCBI、物种数据
  库、蛋白结构库、软件更新）时。
- **AI 可完全关闭**：AI 助手是可选功能，API Key 仅存本地。
- **合并不覆盖**：安装示例数据、导入数据包、局域网接收均只补充空缺字段，不覆盖你已有的
  内容。
