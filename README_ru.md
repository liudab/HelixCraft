# HelixCraft

**Настольная программа для генной инженерии с поддержкой ИИ** · AI-powered gene engineering tools

[简体中文](README.md) · [English](README_EN.md) · [日本語](README_ja.md) · [한국어](README_ko.md) · [Français](README_fr.md) · [Deutsch](README_de.md) · [Español](README_es.md) · [Português](README_pt.md) · **Русский** · [Italiano](README_it.md) · [العربية](README_ar.md) · [हिन्दी](README_hi.md) · [ไทย](README_th.md) · [Tiếng Việt](README_vi.md) · [Bahasa Indonesia](README_id.md) · [Türkçe](README_tr.md) · [Nederlands](README_nl.md) · [Polski](README_pl.md) · [Svenska](README_sv.md) · [Čeština](README_cs.md)

> HelixCraft — настольное приложение для исследований в области молекулярной биологии и генной инженерии. Оно охватывает полный рабочий процесс «найти ген → прочитать последовательности → спроектировать клонирование → виртуальная сборка → экспериментальная проверка → управление данными»: редактор карт векторов, анализ последовательностей, конструирование праймеров, моделирование рестрикции и гель-электрофореза, рабочие процессы клонирования, анализ хроматограмм секвенирования, анализ белков и опциональный ИИ-ассистент. Все данные хранятся локально на вашем компьютере — не нужна ни регистрация, ни облако; интерфейс доступен на 20 языках.
> Полная документация: [简体中文](README.md) · [English](README_EN.md)

## Что можно делать с помощью HelixCraft

- Открыть файл плазмиды, чтобы разобрать состав элементов и сайты рестрикции, и экспортировать изображение карты для публикации;
- полностью смоделировать на компьютере план клонирования Gibson / Golden Gate / рестрикция-лигирование до того, как ставить реакции;
- спроектировать праймеры для клонирования или qPCR-праймеры, пересекающие стыки экзонов, с оценками и обоснованием каждого варианта;
- просмотреть хроматограммы секвенирования, собрать риды и сверить результаты, выровняв их обратно на рекомбинантный вектор;
- разметить дорожки и полосы на фотографии геля и выполнить количественный анализ;
- начав с последовательности белка, проанализировать физико-химические свойства, субклеточную локализацию, сайты модификаций и трёхмерную структуру;
- управлять векторами, генами, праймерами и файлами секвенирования по темам проектов, передавать их между компьютерами лаборатории и регулярно создавать резервные копии.

## Скачивание

Актуальная версия всегда публикуется в канале [**Releases · `latest`**](releases/tag/latest); этот канал одновременно служит источником данных для функции «Проверить обновления» внутри приложения, а файлы в нём заменяются при каждом выпуске. Исторические версии собраны в [списке Releases](releases), у каждой — собственный архив. Лежащий рядом с пакетами `latest.json` — это манифест обновлений, которым пользуется приложение: в нём указаны имя файла, размер в байтах и контрольная сумма SHA-256 каждого установщика, что позволяет убедиться, что загрузка завершена полностью и не была подменена.

| Платформа | Установочный пакет | Способ установки |
|---|---|---|
| Windows 10 / 11 (x64) | `HelixCraft.Setup.<version>.exe` | Запустите мастер установки двойным щелчком |
| Debian / Ubuntu (x86_64) | `helixcraft_<version>_amd64.deb` | Двойной щелчок передаёт пакет системному графическому установщику, или `sudo apt install ./<файл>` |

## Установка

### Windows

- Запустите `HelixCraft.Setup.<version>.exe` и следуйте указаниям мастера (по умолчанию установка для всех пользователей, требуются права администратора).
- Мастер предлагает необязательный компонент **примеров данных** (примеры векторов, рабочие процессы клонирования и плагины данных видов), чтобы новые пользователи могли сразу начать работу; примеры импортируются только тогда, когда соответствующего содержимого ещё нет, и **никогда не перезаписывают уже созданные вами данные**.
- **Установка поверх существующей версии сохраняет все данные.** Каталог данных — `%APPDATA%\HelixCraft` (подбазы видов находятся в `%APPDATA%\HelixCraftData`); удаление программы его не удаляет.

### Linux (Debian / Ubuntu, x86_64)

- Двойной щелчок по `.deb` передаёт его графическому установщику системы (GNOME Software / App Center / KDE Discover / GDebi); эквивалент в терминале: `sudo apt install ./helixcraft_<version>_amd64.deb`.
- Программа устанавливается в `/opt/HelixCraft`, пользовательские данные хранятся в `~/.config/HelixCraft`; **при удалении программы они не удаляются**.
- Рекомендуется установить шрифты CJK (пакет объявляет `Recommends: fonts-noto-cjk`; при установке через `dpkg -i` рекомендации не подтягиваются — пользуйтесь `apt install`).

## Онлайн-обновления

Примерно через 20 секунд после запуска приложение проверяет обновления в фоновом режиме (по умолчанию включено, не чаще одного раза в 24 часа, отключается в настройках). Обнаруженная новая версия только сообщается — **автоматическая загрузка не выполняется**; загрузка идёт по HTTPS с поддержкой докачки и проверкой SHA-256, пакеты, не прошедшие проверку, отклоняются. В Windows установку завершает мастер NSIS, после чего приложение перезапускается автоматически; в Linux загруженный `.deb` передаётся системному установщику пакетов.

## Основные функции

- **Карты векторов и редактирование последовательностей**: кольцевые и линейные карты двунаправленно связаны с текстом последовательности; элементы окрашиваются по типу, поверх показываются сайты рестрикции, места связывания праймеров, ORF и маркеры мутаций; оформление карты (цвета, размеры шрифтов, легенда, видимость) настраивается свободно, с экспортом в SVG / PDF / PNG и другие форматы для иллюстраций к публикациям; последовательность правится напрямую (ввод, удаление, вставка), координаты элементов сдвигаются автоматически, для всех операций доступны 50 шагов отмены и повтора.
- **Интеллектуальная аннотация**: полная последовательность вектора сравнивается с базой элементов, и известные элементы распознаются автоматически (≥99 % совпадения ДНК или ≥90 % совпадения трансляции); устойчивость к антибиотикам, хозяин, промотор, ген-репортёр и другие поля выводятся автоматически с уровнем уверенности и доказательствами, без перезаписи уже имеющихся сведений.
- **Предсказание ORF и онлайн-поиск BLAST**: сканирование всех шести рамок считывания, включая ORF, пересекающие начало координат кольцевых плазмид; выделенный участок отправляется в NCBI (blastn / blastp / blastx и другие программы).
- **Моделирование рестрикции и виртуальный гель-электрофорез**: списки фрагментов в реальном времени для одно-, двух- и многоферментных рестрикций, включая корректную обработку сайтов, пересекающих начало координат кольцевых плазмид; результаты отправляются в симуляцию геля (11 распространённых маркеров вроде DL2000 и 1 kb Ladder, концентрация агарозы, напряжение и длительность пробега), чтобы заранее оценить, разделятся ли нужные полосы при диагностической рестрикции; автоматическая проверка влияния метилирования (Dam / Dcm / CpG); помощник по выбору сайтов рестрикции.
- **Холст рабочих процессов клонирования**: эксперимент собирается как блок-схема — источники последовательностей → дизайн праймеров / оптимизация кодонов → виртуальная ПЦР → рестрикция / очистка → сборка → трансформация / ПЦР колоний / проверка секвенированием → сохранение в базу данных; всего 30 типов узлов, и результат каждого узла **вычисляется в реальном времени**: поменяли вход сверху — всё ниже сразу пересчитывается; стратегии сборки: Gibson, Golden Gate (BsaI / BbsI / BpiI / SapI, с рекомендациями по защитным нуклеотидам), T4-лигирование, TA / TOPO, Gateway LR / BP, BioBrick; по завершении соединений можно просмотреть полную последовательность итоговой рекомбинантной плазмиды — дизайн считается готовым только при совпадении с ожиданиями; поддерживаются отмена/повтор, автосохранение и импорт/экспорт JSON.
- **Холст молекулярных конструкций (бета)**: дизайн в стиле «выберите скелет, добавьте элементы» — скелет берётся из библиотеки векторов, разрывы заполняются элементами, выбирается метод сборки, а программа автоматически генерирует способ линеаризации, все последовательности праймеров, реакционную смесь для сборки, ожидаемые фрагменты ПЦР колоний и предложения по секвенирующим праймерам; сохранить результат разрешается только если продукт совпадает с проектом с точностью до каждого основания.
- **Конструирование праймеров**: универсальный дизайн в трёх режимах (амплификация выбранного участка / поиск праймеров внутри участка / амплификация от флангов) с более чем 50 настраиваемыми параметрами (Tm, GC-состав, длина продукта, стабильность 3′-конца и др.) и топ-20 кандидатами — у каждого Tm, GC %, риск шпилек/димеров и итоговая оценка по 100-балльной шкале; углублённая оценка с обратной связью от человека; мастер qPCR-праймеров автоматически выравнивает мРНК на геном с учётом сплайсинга, строит структуру экзонов и в первую очередь предлагает праймеры, пересекающие стыки экзонов, с оценкой соответствия MIQE и привязкой к гену при сохранении; виртуальная ПЦР (in-silico) для любой пары праймеров; база праймеров (qPCR / универсальные / клонирование / детекция) с привязкой к генам и проектам, импортом/экспортом Excel и журналом правок.
- **Анализ результатов секвенирования**: просмотр хроматограмм AB1 с четырьмя каналами флуоресценции и значениями качества, побазовая сверка с эталонной последовательностью; автоматическая сборка нескольких ридов Sanger алгоритмом CAP3 с получением контигов, глубины покрытия и указанием низкокачественных участков; проверочное выравнивание ридов на ваш рекомбинантный вектор с автоматическим выбором лучшего направления цепи (в том числе для кольцевых векторов через начало координат) и схемой «элементы вектора + раскладка ридов», окрашенной по степени совпадения; также множественное выравнивание (ClustalW) и построение филогенетических деревьев.
- **ИИ-анализ изображений гелей**: мастер из трёх шагов — открыть фотографию геля → встроенная модель глубокого обучения автоматически распознаёт дорожки и полосы (можно добавлять, удалять и подстраивать вручную) → количественный анализ; после выбора дорожки маркера, типа лестницы и количества ДНК в референсной полосе автоматически строится калибровочная кривая размеров, и для каждой полосы выдаются **размер фрагмента и количество ДНК** (метод интегральной оптической плотности); экспорт размеченных изображений (PNG / JPG / BMP / TIF) и результатов в формате JSON.
- **Анализ белков**: три связанных представления — схема топологии (трансмембранные участки, сигнальные пептиды, вторичная структура), панель аминокислотной последовательности и трёхмерная структура (автоматически загружается из RCSB PDB / AlphaFold DB); щелчок по любому сайту или участку подсвечивает его одновременно в последовательности и в структуре; мгновенные локальные расчёты: молекулярная масса, изоэлектрическая точка, гидрофобность, аминокислотный состав, предсказание субклеточной локализации, семь типов сайтов посттрансляционных модификаций, неупорядоченные и антигенные участки; онлайн-уточнение через InterProScan и BLAST с переносом проверенных аннотаций Swiss-Prot.
- **Управление лабораторными данными**: пять баз данных — библиотека векторов (шаблонные / рекомбинантные, двухуровневые рабочие группы), база последовательностей, база праймеров, база ферментов (580+ рестрикционных ферментов с сайтами узнавания, картами разрезания и температурными данными, можно добавлять свои) и менеджер проектов; рабочая группа векторов упаковывается в файл `.hcvec` для коллеги, а два компьютера с HelixCraft в одной локальной сети обмениваются данными по шифрованному каналу с 8-значным кодом сопряжения — принимающая сторона только заполняет пустые поля и ничего не перезаписывает; автоматическое резервное копирование при запуске (5 копий), ручная полная копия одним ZIP-архивом и восстановление в один клик; перед удалением вектора / гена / праймера выводится список затрагиваемых связанных данных, а объём удаления выбираете вы.
- **Опциональный ИИ-ассистент**: работает с любым совместимым с OpenAI интерфейсом большой модели после настройки (API-ключ хранится только на вашем компьютере); он «видит», какой ген / вектор / окно у вас открыты, и может по просьбе переключать страницы, находить записи, запрашивать и изменять данные — изменения идут ровно тем же путём, что и ручное редактирование, и их можно отменить; ИИ извлекает из текста методики структурированный план клонирования (скелет, вставка, ферменты, метод сборки), после чего детерминированный движок программы строит праймеры и рекомендации — **ИИ только понимает текст и никогда не создаёт последовательности оснований**; **без настройки ИИ у каждой функции есть полностью ручной путь, и программа остаётся полнофункциональной.**

## Плагины данных видов

Аннотации генов и данные экспрессии подключаются через «плагины данных видов», которые устанавливаются, включаются и удаляются на странице настроек. В установочный пакет встроены аннотационные данные риса (около 100 000 записей); аннотации, последовательности и изображения, полученные онлайн, автоматически сохраняются в локальный кэш и по умолчанию читаются из него — всё доступно и без интернета. Даже без плагинов гены любого вида можно импортировать напрямую из NCBI.

| Плагин | Источники данных | Что вы получаете |
|---|---|---|
| Рис (Rice) | RAP-DB, MSU-RGAP, RiceData, RiceXPro | аннотации локусов, структура экзонов, синонимы, фенотипы мутантов, карты экспрессии во времени и пространстве (значения + изображения), последовательности всех версий, перевод идентификаторов между базами |
| Ensembl Plants | Ensembl Plants, EBI Expression Atlas | поиск генов по 100+ видам, загрузка последовательностей, GO-аннотации, экспрессия RNA-Seq |
| Phytozome | JGI Phytozome | поиск генов, модели генов, последовательности CDS / cDNA / белков, домены, гомологичные гены |
| ePlant (BAR) | BAR eFP Browser | цветные пиктограммы тканевой экспрессии и уровни экспрессии по тканям для 13 видов |

## Безопасность и конфиденциальность данных

- **Все данные хранятся локально**: ничего не отправляется на серверы; сетевые обращения происходят только по вашему явному запросу онлайн-данных (NCBI, базы данных видов, банки структур белков, обновления программы).
- **ИИ полностью опционален**: ассистенту нужен ваш собственный API-ключ, который хранится только локально; без настройки ИИ у каждой функции есть ручной путь.
- **Слияние никогда не перезаписывает**: установка примеров данных, импорт пакетов и приём передач по локальной сети только заполняют пустые поля и не трогают существующее содержимое.
