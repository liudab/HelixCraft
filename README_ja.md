# HelixCraft

**AI 搭載の遺伝子工学支援デスクトップソフトウェア** · AI-powered gene engineering tools

[简体中文](README.md) · [English](README_EN.md) · **日本語** · [한국어](README_ko.md) · [Français](README_fr.md) · [Deutsch](README_de.md) · [Español](README_es.md) · [Português](README_pt.md) · [Русский](README_ru.md) · [Italiano](README_it.md) · [العربية](README_ar.md) · [हिन्दी](README_hi.md) · [ไทย](README_th.md) · [Tiếng Việt](README_vi.md) · [Bahasa Indonesia](README_id.md) · [Türkçe](README_tr.md) · [Nederlands](README_nl.md) · [Polski](README_pl.md) · [Svenska](README_sv.md) · [Čeština](README_cs.md)

> HelixCraft は、分子生物学と遺伝子工学の研究のためのデスクトップアプリケーションです。「遺伝子を調べる → 塩基配列を読む → クローニングを設計する → 仮想アセンブリ → 実験で検証 → データ管理」という一連のワークフローをワンストップでカバーします。ベクターマップ編集、塩基配列解析、プライマー設計、制限酵素消化とゲル電気泳動のシミュレーション、クローンワークフロー、シークエンシングクロマトグラム解析、生物種データの検索、タンパク質解析に加えて、オプションの AI アシスタントを備えています。すべてのデータは自分のコンピューター上に保存され、アカウント登録もクラウドへの依存も不要です。インターフェースは 20 言語に対応しています。
> 完全なドキュメント：[简体中文](README.md) · [English](README_EN.md)

## できること

- プラスミドマップファイルから構成要素と制限酵素サイトを一目で把握し、論文・発表用のマップ画像を書き出せます。
- 実際に反応を調整する前に、Gibson / Golden Gate / 制限酵素-ライゲーションなどの実験計画をコンピューター上で完全にシミュレーションできます。
- クローニング用プライマーやエクソン接合部をまたぐ qPCR 定量プライマーを、スコアと評価の根拠付きで設計できます。
- シークエンシングのクロマトグラムを確認し、リードをアセンブリして、結果を組換えベクターにアラインメントして照合できます。
- ゲル写真にレーン/バンドの注釈を付けて定量解析できます。
- タンパク質配列から、物理化学的性質、細胞内局在、修飾サイト、三次元構造を解析できます。
- 研究課題ごとにベクター・遺伝子・プライマー・シークエンシングファイルを管理し、研究室の複数の PC 間で転送したり、定期的にバックアップしたりできます。

## ダウンロード

最新バージョンは常に [**Releases · latest チャンネル**](releases/tag/latest) で公開されます。

| プラットフォーム | インストーラー | インストール方法 |
|---|---|---|
| Windows 10 / 11（x64） | `HelixCraft.Setup.<version>.exe` | ダブルクリックでセットアップウィザードを実行 |
| Debian / Ubuntu（x86_64） | `helixcraft_<version>_amd64.deb` | ダブルクリックしてシステムのグラフィカルインストーラーに渡すか、`sudo apt install ./<ファイル>` を実行 |

`latest` チャンネルはアプリ内「アップデートの確認」のデータソースでもあり、資産はリリースごとに差し替えられます。過去のバージョンは [Releases 一覧](releases) に、バージョンごとの独立したアーカイブとして保存されています。同じディレクトリの `latest.json` はアプリが使用する更新マニフェストで、各インストーラーのファイル名・バイト数・SHA-256 ハッシュが記載されており、ダウンロードが完全で改ざんされていないことを検証できます。

## インストール

### Windows

- `HelixCraft.Setup.<version>.exe` をダブルクリックし、ウィザードに従ってインストールします（既定では全ユーザー向けにインストールされ、管理者権限が必要です）。
- ウィザードではオプションの**サンプルデータ**コンポーネント（サンプルベクター、クローンワークフロー、生物種データプラグイン）を選択できます。サンプルデータは対応する内容がまだ存在しない場合にのみ取り込まれ、**既に作成済みのデータを上書きすることは決してありません**。
- **上書きインストールでも既存データはすべて保持されます**。データディレクトリは `%APPDATA%\HelixCraft`（生物種プラグインのサブデータベースは `%APPDATA%\HelixCraftData`）で、アンインストールしても削除されません。

### Linux（Debian / Ubuntu、x86_64）

- `.deb` をダブルクリックするとシステムのグラフィカルインストーラー（GNOME Software / App Center / KDE Discover / GDebi など）に渡されます。端末からは `sudo apt install ./helixcraft_<version>_amd64.deb` を実行してください。
- プログラムは `/opt/HelixCraft` に、ユーザーデータは `~/.config/HelixCraft` にインストールされ、**アンインストールしても削除されません**。
- 日本語などの CJK フォントがシステムにインストールされていることを推奨します。

## オンラインアップデート

アプリは起動の約 20 秒後にバックグラウンドでアップデートを確認します（既定で有効、24 時間に最大 1 回、設定で無効化可能）。新しいバージョンが見つかった場合は通知のみで、**自動ダウンロードは行いません**。ダウンロードは HTTPS で、レジューム（中断からの再開）と SHA-256 検証に対応し、検証に失敗したインストーラーは拒否されます。Windows では NSIS ウィザードがインストールを完了してアプリを自動的に再起動し、Linux ではダウンロードした `.deb` をシステムのソフトウェアインストーラーに渡します。

## 主な機能

- **ベクターマップと塩基配列編集**：環状/線形マップと配列テキストが双方向に連動し、要素はタイプ別に着色。制限酵素サイト、プライマー結合位置、ORF、変異マーカーを重ねて表示できます。マップのスタイル（色・フォントサイズ・凡例・表示/非表示）は自由にカスタマイズでき、論文図として SVG / PDF / PNG などに書き出せます。配列はキー入力・削除・ペーストで直接編集でき、挿入・削除後も要素の座標は自動調整。塩基配列と要素のすべての操作に 50 段階の取り消し/やり直しに対応しています。
- **スマートアノテーション**：ベクター全配列を要素データベースと照合して既知の要素を自動認識（DNA 相同性 99% 以上または翻訳一致 90% 以上で認定、一括取り込み前に 1 件ずつプレビュー確認）し、抗生物質耐性・宿主・プロモーター・レポーター遺伝子などのフィールドを信頼度と証拠付きで自動推論します。既存の情報は上書きしません。
- **ORF 予測と BLAST オンライン検索**：6 視読枠の走査（環状プラスミドの原点をまたぐ ORF にも対応）で ORF を予測し、翻訳産物を配列データベースに保存できます。選択した配列を NCBI へ BLAST 検索（blastn / blastp / blastx など 5 種類のプログラム）に送信できます。
- **制限酵素消化シミュレーションと仮想ゲル電気泳動**：単一/二重/多重消化のフラグメントリストをリアルタイムで表示し、環状プラスミドの原点をまたぐ消化も正しく処理します。消化結果をゲルシミュレーションに送り、マーカー（DL2000、1kb Ladder など 11 種類）、アガロース濃度、電圧、走行時間を指定すると、文献に基づく移動モデルでバンド位置を推定し、鑑定消化で目的のバンドを分離できるかを事前確認できます。Dam / Dcm / CpG メチル化の影響も自動チェックします。
- **クローンワークフローキャンバス**：フローチャートのように実験を接続します（配列ソース → プライマー設計/コドン最適化 → 仮想 PCR → 消化/精製 → アセンブリ → 形質転換/コロニー PCR/シークエンシング検証 → データベースへ保存、全 30 種類のノード）。各ノードの出力はリアルタイムに計算され、上流の入力を変更すると下流が即座に再シミュレーションされます。Gibson、Golden Gate（BsaI / BbsI / BpiI / SapI、保護塩基の推奨付き）、T4 連結、TA / TOPO クローニング、Gateway LR / BP、BioBrick に対応し、接続完了後には最終組換えプラスミドの全配列を確認できます。
- **分子構築キャンバス（Beta）**：「バックボーンを選び、要素を差し込む」形式の設計に適しています。ベクターライブラリからバックボーンを選び、欠口に要素を追加し、アセンブリ法を選ぶと、線形化方式、全プライマー配列、アセンブリ条件、コロニー PCR 検証フラグメント、シークエンシングプライマー候補を自動生成します。産物が設計と塩基単位で一致した場合のみデータベースに保存できます。
- **プライマー設計**：汎用プライマー設計は 3 モード（選択領域の増幅/選択領域内での探索/フランキング領域からの増幅）に対応し、Tm、GC、産物長、3′ 末端安定性など 50 項目以上のパラメータを調整できます。Top20 候補にそれぞれ Tm、GC%、ヘアピン/ダイマーリスク、100 点満点の総合スコアを付けます。qPCR 定量プライマーウィザードは mRNA とゲノムのスプライシングアラインメントを自動実行してエクソン構造を作成し、エクソン接合部をまたぐプライマーを優先する段階的な設計でゲノム DNA 汚染の干渉を回避します。結果には MIQE 準拠スコアが付き、保存時に遺伝子へ自動関連付けされます。設計済みプライマーはプライマーデータベースで管理され、バーチャル PCR で予想増幅産物のサイズと非特異的増幅の有無を事前確認できます。
- **シークエンシング結果解析**：AB1 ファイルの 4 チャンネル蛍光ピークと品質値を表示し、参照配列と塩基ごとに照合できます。複数の Sanger リードを CAP3 アルゴリズムで自動アセンブリし、コンセンサス配列・カバー深度・低品質領域のヒントを出力します。シークエンシングリードを組換えベクターにアラインメントして検証し、一致率で色分けした「ベクター要素+リード配置」図でミスマッチ/挿入/欠失を一目で確認できます（ClustalW によるマルチプルアラインメントと系統樹構築にも対応）。
- **ゲル画像 AI 解析**：内蔵の深層学習モデルがゲル写真のレーンとバンドを自動認識し（手動での追加・削除・ドラッグ調整も可能）、マーカーレーンと参照バンドの量からサイズ標準曲線を自動フィッティングして、各バンドの断片サイズと DNA 量を積算光密度法で定量します。
- **タンパク質解析**：トポロジー図（膜貫通領域、シグナルペプチド、二次構造）↔ アミノ酸配列パネル ↔ 三次元構造（RCSB PDB / AlphaFold DB から自動取得）の 3 ビューが連動し、任意のサイトや領域をクリックすると配列と構造が同時にハイライトされます。分子量・等電点・疎水性・アミノ酸組成、細胞内局在予測、リン酸化/ユビキチン化/糖基化など 7 種類の翻訳後修飾サイト、無秩序領域・低複雑度領域・コイルドコイル・抗原性領域をローカルで即時解析でき、評価の高い候補サイトは InterProScan ドメイン走査と BLAST 相同検索に自動送信して Swiss-Prot の検証済みアノテーションを補完します（上書きなし・出典を明示）。
- **ラボデータ管理**：ベクターライブラリ、配列データベース、プライマーデータベース、酵素データベース（580 種以上の制限酵素の認識配列・切断位置・タイプ・末端・温度資料、カスタム酵素にも対応）、プロジェクトマネージャーの 5 つのデータベースを統合管理します。ベクターワークグループ全体を `.hcvec` ファイルとして同僚と共有したり、同一 LAN 内の 2 台の PC 間で 8 桁のペアリングコードによる暗号化転送を行ったりできます。起動時の自動バックアップ（5 世代保持）、手動の完全バックアップ（単一 ZIP）とワンクリック復元、削除前の影響データの一覧表示と範囲選択により、データを多層的に保護します。
- **AI アシスタント（オプション）**：OpenAI 互換の大規模言語モデル API を設定すれば利用可能です（API キーはローカルにのみ保存）。現在開いている遺伝子/ベクター/ウィンドウを認識してページ切替やデータの照会・変更ができ、変更は手動編集とまったく同じ経路を通るため取り消し可能です。文献の方法節や口頭の説明を貼り付けると、AI が構造化されたクローニング計画（バックボーン、挿入断片、酵素、アセンブリ法）を抽出し、ソフトウェアの決定論的エンジンがプライマーと実験ガイドを生成します。**AI は文章の理解のみを担当し、塩基配列は一切生成しません**。AI を設定しなくても、すべての機能に手動の操作パスがあり、ソフトウェアは完全に利用可能です。

## 生物種データプラグイン

遺伝子アノテーションと発現データは生物種プラグイン経由で取り込み、設定ページでインストール/有効化/アンインストールできます。インストーラーにはイネのアノテーションデータ（約 10 万件）が同梱されており、オンラインから取得した注釈・配列・画像は自動的にローカルキャッシュへ保存されるため、オフラインでも閲覧できます（既定ではローカルキャッシュを読み込み、更新時のみ再接続します）。プラグインをインストールしなくても、NCBI から任意の生物種の遺伝子を直接取り込めます。

| プラグイン | 対応データソース | 取得できる主な内容 |
|------|-----------|--------------|
| イネ（Rice） | RAP-DB、MSU-RGAP、RiceData、RiceXPro | 遺伝子座アノテーション、エクソン構造、同義語、変異体表現型、時空間発現マップ（数値+画像）、各バージョンの配列、データベース横断の ID 変換 |
| Ensembl Plants | Ensembl Plants、EBI Expression Atlas | 100 以上の生物種の遺伝子検索、配列ダウンロード、GO アノテーション、RNA-Seq 発現データ |
| Phytozome | JGI Phytozome | 遺伝子検索、遺伝子モデル、CDS / cDNA / タンパク質配列、ドメイン、相同遺伝子 |
| ePlant（BAR） | BAR eFP Browser | 13 生物種の組織発現カラーピクトグラフと組織別発現量 |

## データの安全性とプライバシー

- **すべてのデータはローカル保存**：サーバーへは一切アップロードされません。ネットワーク通信は、NCBI・生物種データベース・タンパク質構造データベース・ソフトウェア更新など、オンラインデータを自分で要求した場合にのみ発生します。
- **AI は完全にオプション**：AI アシスタントは任意機能で、API キーはローカルにのみ保存されます。AI を設定しない場合でも、すべての機能に手動の操作パスがあります。
- **マージは上書きなし**：サンプルデータのインストール、データパッケージの取り込み、LAN 経由の受信は、いずれも空欄の補完のみを行い、既存の内容を上書きしません。

| 方向 | フォーマット |

| 開く/読み込み | GenBank（`.gb` `.gbk`）、FASTA（`.fasta` `.fa` `.faa`）、SnapGene（`.dna`）、EMBL（`.embl`）、シークエンシングクロマトグラム（`.ab1`）、プライマー Excel（`.xlsx`）、タンパク質アノテーション（UniProtKB / GFF3 / InterProScan / GenPept）、タンパク質構造（PDB / mmCIF）、HelixCraft パッケージ（遺伝子パッケージ / `.hcvec` ベクターパッケージ / `.hcp` タンパク質パッケージ） |
